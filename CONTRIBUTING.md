# Contributing

ThinkSo is not currently accepting outside code or documentation contributions.

The repository is public so people can inspect the work and follow its development, but it is not presently open source and grants no general reuse or commercial license. Please do not open pull requests containing contributions unless the repository owner has explicitly requested them in advance.

Bug reports and product feedback may be submitted through GitHub Issues once issue intake is enabled. Submitting feedback does not transfer ownership of code or grant a software license.

This policy preserves clear ownership while the project is young and leaves room for the owner to adopt an open-source license, such as the GPL, later.
